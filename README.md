This is a [React 19](https://react.dev/) + [Vite](https://vite.dev/) project integrated with an [Express.js](https://expressjs.com/) backend and [MongoDB Atlas](https://www.mongodb.com/) database for [Sakuin](https://sakuinfree.vercel.app/) — Smart Personal Finance & Quick Expense Tracker.

## Getting Started

First, run the development server:

```bash
npm run dev
# or to run both frontend and backend server concurrently:
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:5173](http://localhost:5173/) with your browser to see the result.

You can start editing the page by modifying `src/App.jsx` or components in `src/pages/`. The page auto-updates as you edit the file.

This project uses [Tailwind CSS](https://tailwindcss.com/) for modern glassmorphism styling, [Lucide Icons](https://lucide.dev/), [Framer Motion](https://www.framer.com/motion/) for fluid animations, and [MongoDB Atlas](https://www.mongodb.com/) for cloud database management.
